# 🌍 Geo-Explorer — DIO + IBM Bob
# Frontend-Geo-Explorer-DIO
Projeto Geo-Explorer desenvolvido para o desafio ‘Construindo seu Primeiro Produto com um Agente de IA’ da DIO. Este repositório contém a implementação Front-End do sistema de exploração de trilhas de aprendizagem, desafios de código e certificados fictícios, utilizando o IBM Bob como agente de apoio.

## 📘 O que é o Geo-Explorer

O Geo-Explorer é uma aplicação em Node.js criada para o desafio **“Construindo seu Primeiro Produto com um Agente de IA”** da DIO Global.  
Ele permite explorar trilhas de aprendizagem, gerar desafios de código e emitir certificados fictícios, utilizando uma base de dados simples e comandos próprios.

O projeto foi desenvolvido com foco na tecnologia **Front-End**, simulando trilhas de estudo para iniciantes, intermediários e avançados.
## 📚 Base de Trilhas (Resumo)

O arquivo `data/trilhas.json` contém trilhas fictícias para **Front-End**, divididas em três níveis:

### 🔹 Iniciante  
- HTML  
- CSS  
- JavaScript  
*Fundamentos essenciais para iniciar no Front-End.*

### 🔹 Intermediário    
*Construção de aplicações modernas com React.*

### 🔹 Avançado  
- Performance  
- Arquitetura  
- Testes  
 Aprofundamento em técnicas avançadas de Front-End.*

## 🚀 Como executar o projeto

Antes de tudo, instale as dependências:

npm install

Para rodar o projeto, utilize o comando:

node index.js

Os comandos específicos são explicados na seção abaixo.

---

## 🛠 Como usar os comandos

O Geo-Explorer possui três comandos principais:

### 🔹 1. Trilha
Retorna os módulos da trilha escolhida.

node  index.js 
trilha frontend iniciante

### 🔹 2. Desafio

Gera um desafio baseado no nível informado.

node  index.js 

desafio frontend intermediario

### 🔹 3. Certificado

Gera um certificado fictício com nome e trilha.

node  index.js 

certificado "Seu Nome" frontend avancado

---

## 🧪 Como executar os testes

Os testes foram criados usando Node.js puro, sem bibliotecas externas.

Execute cada teste individualmente:

node test/trilha.test.js

node test/desafio.test.js

node test /certificado.test.js

Cada teste imprime no console o resultado esperado do comando correspondente.
