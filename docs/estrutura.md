# Estrutura do Projeto Geo Explorer

## Pastas

| Pasta       | Descrição                                              |
|-------------|--------------------------------------------------------|
| `/data`     | Arquivos de dados geográficos (JSON, CSV, etc.)        |
| `/commands` | Módulos de comandos de linha de interface CLI          |
| `/tests`    | Testes automatizados do projeto                        |
| `/docs`     | Documentação do projeto                                |

## Arquivos

| Arquivo        | Descrição                                         |
|----------------|---------------------------------------------------|
| `index.js`     | Ponto de entrada principal da aplicação           |
